# DESIGN_SYSTEM.md — визуальный язык приложения ("Aurora")

Источник — референс "Aurora Sign Up" (motionsites.ai), адаптированный под реальный
функциональный контракт приложения: single-user, только логин (см. `specs/core.md`,
без регистрации через API и без OAuth). Применяется ко всем экранам, не только к логину.

## 1. Технологии

- Tailwind CSS (v4)
- `motion/react` — анимации (уже не входил в стек CLAUDE.md §3, добавляется этим файлом)
- `lucide-react` — иконки
- `shadcn/ui` — где нужны сложные примитивы (dropdown, dialog, toast) — используются как
  структурная база, но перекрашиваются под токены ниже, а не под дефолтную тему shadcn

## 2. Токены

- Шрифт: **Inter** (300, 400, 500, 600, 700), импорт из Google Fonts
- `--font-sans: "Inter", ui-sans-serif, system-ui, sans-serif;`
- `--color-brand-gray: #1A1A1A` — основной цвет непрозрачных карточек/полей ввода
- База: `bg-black text-white antialiased font-sans` на `body`
- Текстовая иерархия по прозрачности белого: `text-white` (основной) →
  `text-white/60` (подзаголовки) → `text-white/40` (вспомогательный) →
  `text-white/20` (placeholder)
- Радиусы: `rounded-xl` — поля ввода и кнопки, `rounded-3xl` — крупные панели/карточки
- `selection:bg-white/30` на корневом контейнере

## 3. Layout-конвенции

- Полноэкранный тёмный canvas с отступом `p-2` (`lg:p-4`)
- Экраны в духе "hero + форма" (логин, будущий онбординг) — двухколоночная раскладка:
  левая панель ~52% ширины (визуальный акцент — видео/градиент), правая — контент/форма
- На мобильных — левая панель скрыта (`hidden lg:flex`), правая колонка занимает всю ширину

## 4. Анимационные конвенции (`motion/react`)

- **Каскадное появление контейнера:** `opacity: 0 → 1`, `staggerChildren: 0.15`,
  `delayChildren: 0.2`; дочерние элементы — `y: 10 → 0`, `opacity: 0 → 1`,
  `duration: 0.5`
- **Простое появление панели** (например, колонка формы): `opacity: 0 → 1`,
  `duration: 0.8`, `ease: "easeOut"`, без каскада
- **Нажатие кнопки:** `active:scale-[0.98]`

## 5. Переиспользуемые компоненты

### `<InputGroup>`
`label` (`text-sm font-medium text-white`) + `input` (`bg-brand-gray border-none
rounded-xl h-11 px-4 text-white placeholder:text-white/20 focus:ring-2
focus:ring-white/20`)

### Основная кнопка
`w-full h-14 bg-white text-black font-semibold rounded-xl hover:bg-white/90
active:scale-[0.98]`

### `<StepItem>` (для будущих многошаговых сценариев — не для логина)
Пронумерованный пункт списка с активным/неактивным состоянием:
- активный — `bg-white text-black border border-white`, номер — `bg-black text-white`
- неактивный — `bg-brand-gray text-white border-none`, номер — `bg-white/10 text-white/40`

**Не переносится из референса:** `<SocialButton>` (Google/Github) и разделитель "Or" —
в приложении нет OAuth, компонент не нужен.

## 6. Экран логина (`core`) — первое конкретное применение

Двухколоночный, по конвенции из §3:

- **Левая панель** — видео (`frontend/public/assets/hero-background.mp4`, лицензия
  MotionSite Free Tier проверена — использование в собственном приложении разрешено,
  запрещено только распространять сам файл как отдельный шаблон третьим лицам), поверх —
  каскадный `motion.div` (§4): логотип/название приложения,
  заголовок (например "С возвращением"), короткое описание. Без `<StepItem>` — это
  список шагов онбординга из референса, здесь неприменим (нет флоу регистрации)
- **Правая панель** — простое появление (§4, без каскада): заголовок "Вход",
  `<InputGroup>` для email, `<InputGroup>` для пароля с иконкой `Eye` (toggle показать/
  скрыть, `lucide-react`), основная кнопка "Войти"
- **Не включается:** имя/фамилия, Google/Github, разделитель "Or", ссылка "Member of
  the team? Log in" (это и есть единственный экран входа, ссылке некуда вести)

## 7. Область применения

Токены, анимационные конвенции и компоненты из этого файла — общий визуальный язык для
всех модулей (`habits`, `tasks`, `finance`, `food`), не только для логина. Каждый новый
экран стилизуется по этому файлу, а не по дефолтной теме shadcn/ui и не изобретается
заново — см. обновлённый `WORKFLOW.md` §5 и `PROMPTS.md` (шаги 6–7).
